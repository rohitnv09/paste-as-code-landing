Clipboard First

No need to save files or mess with drag-and-drop. Copy a screenshot directly on your machine (macOS only, Linux/Windows coming soon), run the command, get text instantly.

Save LLM Tokens

Stop pasting heavy images into ChatGPT or Claude. Pass pure Markdown text instead to save context windows and get faster responses.

Developer Tuned

Upscales small images, inverts dark themes automatically, and sharpens text before OCR for maximum accuracy on code and stack traces.

Secure and Lightweight

Powered by local Tesseract OCR. No AI, no cloud processing, and no data stealing. Everything runs locally on your machine, fast and lightweight.

Ready to speed up your workflow?

Install globally via npm or run via npx. Requires Node 20+.

npm install -g paste-as-code

The magic trick in 3 steps

1

Copy Image

Take a screenshot of code, terminal error, or stack trace to your clipboard.

2

Run CLI Command

pac -cb -c

macOS

The image is processed and code is extracted.

3

Paste Output

Clean, syntax-fenced Markdown is now in your clipboard. Paste it anywhere.

Cheat Sheet

Command What it does
pac -cb -c Read clipboard image, OCR it, and copy Markdown back. macOS
pac -cb Read screenshot from clipboard and print to terminal. macOS
pac file.png OCR an image file and print Markdown.
pac file.png -l ts Force the Markdown fence language to TypeScript.
